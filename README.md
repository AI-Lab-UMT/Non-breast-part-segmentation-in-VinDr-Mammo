# Removing Non-Breast Anatomical Structures in Mammograms

U-Net segmentation of unwanted anatomical structures (UWAS) in full-field
digital mammograms, and evaluation of their removal as a preprocessing step
for benign–malignant classification.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.XXXXXXX.svg)](https://doi.org/10.5281/zenodo.XXXXXXX)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

---

## Overview

Unwanted anatomical structures (UWAS) are elements other than the breast —
the pectoral muscle, parts of the contralateral breast, abdominal tissue —
that are captured during mammographic acquisition. In the first 1,000
images of VinDr-Mammo they appear in more than 70% of cases.

This repository contains the code and reference annotations for a U-Net
that segments UWAS other than the pectoral muscle, and for the downstream
experiment measuring what their removal does to a ResNet50 benign–malignant
classifier.

**Scope note.** The reference masks are generated by a per-image geometric
rule: a single horizontal transition row `k` below which non-zero pixels
are labelled UWAS. Segmentation scores therefore express agreement with
this rule, not with an independent anatomical delineation. See
[Limitations](#limitations).

## Data availability

**This repository does not redistribute mammographic images.**

VinDr-Mammo is distributed through PhysioNet under a credentialed-access
license that does not permit redistribution. To reproduce the work you
need to obtain the dataset yourself:

1. Complete PhysioNet credentialing and sign the data use agreement.
2. Download VinDr-Mammo v1.0.0 from PhysioNet.
3. Point `config.yaml` at your local copy.

What this repository **does** provide:

| Artifact | Description |
|---|---|
| `annotations/transition_rows.csv` | `image_id, k` for every annotated image — the full manual annotation effort |
| `annotations/test1_rows.csv`, `test2_rows.csv` | Held-out groups (cases 1000–1100 and 1100–1200) |
| `src/build_masks.py` | Regenerates every reference mask from `k` and the source images |
| `src/` | Training, evaluation and classification code |
| `weights/` | Trained U-Net weights |

Running `build_masks.py` on your own copy of VinDr-Mammo reproduces the
exact mask set used in the paper.

## Reproducing the results

```bash
# 1. Regenerate reference masks from the transition-row annotations
python src/build_masks.py --config config.yaml

# 2. Train the U-Net (5-fold cross-validation)
python src/train_unet.py --config config.yaml --folds 5

# 3. Evaluate segmentation on the folds and the two held-out groups
python src/evaluate.py --weights weights/unet_best.h5

# 4. Downstream classification under X1 / X2 / X3
python src/classify.py --config config.yaml --runs 100
```

To skip training and evaluate the published weights directly, run step 3
with `--weights weights/unet_paper.h5`.

### Preprocessing configurations

| | Description |
|---|---|
| **X1** | Direct resize to 256×256 |
| **X2** | Background removal (crop to breast bounding box), then resize |
| **X3** | UWAS elimination, then background removal, then resize |

## Results

Five-fold cross-validation, segmentation:

| Metric | Mean | Std |
|---|---|---|
| Accuracy | 0.9997 | <10⁻⁴ |
| Sensitivity | 0.9506 | 5.57×10⁻³ |
| Specificity | 0.9999 | <10⁻⁴ |
| Dice | 0.9725 | 2.24×10⁻³ |

Held-out groups (Dice): Test 1 = 97.68%, Test 2 = 98.85%.

Accuracy and Specificity are close to saturation because background pixels
can represent up to 99.95% of a mammogram; Dice and Sensitivity are the
informative metrics here.

Downstream classification improves progressively X1 → X2 → X3 in Accuracy,
AUC and F1-score. The effect is small and consistent rather than large.

## Limitations

Stated here because they affect how the outputs of this repository should
be read:

- Reference masks come from a per-image row threshold, not free-form
  delineation, and were produced by a single annotator without radiological
  review. No inter-annotator agreement is available.
- No classical baseline (e.g. horizontal intensity profile analysis) is
  implemented, so the benefit of a learned model over a rule-based
  transition-row detector is not quantified.
- X3 differs from X2 both in what is removed and in the resulting scale of
  the breast within the fixed input. The two effects are not separated. A
  control condition narrowing the crop by an equivalent but anatomically
  arbitrary amount would be needed.
- Confidence intervals over the 100 classification runs describe run-to-run
  variability on a fixed image set, not sampling uncertainty. No hypothesis
  test is performed.
- Labels are BI-RADS categories, not histopathologically confirmed
  outcomes.
- Evaluation is in-distribution only; no external or multi-vendor
  validation.
