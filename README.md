# Removing Non-Breast Anatomical Structures in Mammograms

U-Net segmentation of unwanted anatomical structures (UWAS) in full-field
digital mammograms, and evaluation of their removal as a preprocessing step
for benign–malignant classification.

Everything here is a Jupyter notebook, so the work can be inspected and run
cell by cell without building a package.

---

## What this is

UWAS are elements other than the breast — parts of the contralateral
breast, abdominal tissue, the pectoral muscle — captured during
mammographic acquisition. In the first 1,000 images of VinDr-Mammo they
appear in more than 70% of cases.

This repository contains the notebooks, the reference masks and the trained
weights for a U-Net that segments UWAS other than the pectoral muscle, plus
the downstream experiment measuring what their removal does to a ResNet50
benign–malignant classifier.

**Scope note.** The reference masks are generated by a per-image geometric
rule: a single horizontal transition row `k`, below which non-zero pixels
are labelled UWAS. Segmentation scores therefore express agreement with
this rule, not with an independent anatomical delineation. See
[Limitations](#limitations).

### Notebooks

| Notebook | What it does |
|---|---|
| `data_cretion_for_segmentation.ipynb` | Reads the VinDr-Mammo DICOM files and the annotation CSVs, applies the transition-row rule, and writes the paired image/mask set used for training |
| `Segmentation_of_other_part_of_the_brest_1.ipynb` | Builds the U-Net (32→512 filters, encoder–decoder with skip connections), trains it with the hybrid Focal + Dice + IoU objective, and evaluates ACC / SEN / SPC / Dice |
| `Image_Downsizing_Report_and_Classification_Performance.ipynb` | Measures the non-breast proportion of the cropped macro ROI with and without UWAS elimination, then runs the ResNet50 experiment under the X1 / X2 / X3 preprocessing conditions with 95% confidence intervals over 100 runs |

## Data

**The mammographic images are not redistributed here.**

VinDr-Mammo is released through PhysioNet under a credentialed-access
license that does not permit redistribution. To run the notebooks you need
to obtain the dataset yourself:

1. Complete PhysioNet credentialing and sign the data use agreement.
2. Download VinDr-Mammo v1.0.0 (DICOM images plus
   `breast-level_annotations.csv`, `finding_annotations.csv`,
   `metadata.csv`).
3. Update the dataset paths at the top of each notebook — they currently
   point at a local Windows drive (`E:/PhD/V_M_Dataset/`).
4. Run `data_cretion_for_segmentation.ipynb` to regenerate the 256×256
   images. It reproduces exactly the set used in the paper.

What **is** provided:

- `mask_error.zip` — the 1,000 reference masks, the annotation work itself
- `test_1.zip`, `test_2.zip` — the two held-out groups (VinDr-Mammo cases
  1000–1100 and 1100–1200) with their masks
- `error_in_mammo_segmentation.h5` — the trained U-Net

### Preprocessing conditions

| | Description |
|---|---|
| **X1** | Direct resize to 256×256 |
| **X2** | Background removal (crop to breast bounding box), then resize |
| **X3** | UWAS elimination, then background removal, then resize |

The U-Net operates at 256×256 but the predicted mask is upsampled back to
the original resolution, so elimination is applied to the full-size
mammogram before cropping.

## Results

Five-fold cross-validation, segmentation:

| Metric | Mean | Std |
|---|---|---|
| Accuracy | 0.9997 | <10⁻⁴ |
| Sensitivity | 0.9506 | 5.57×10⁻³ |
| Specificity | 0.9999 | <10⁻⁴ |
| Dice | 0.9725 | 2.24×10⁻³ |

Held-out groups (Dice): Test 1 = 97.68%, Test 2 = 98.85%.

Accuracy and Specificity sit near saturation because background pixels can
represent up to 99.95% of a mammogram; Dice and Sensitivity are the
informative metrics.

Cropping to the breast bounding box alone leaves a median of roughly 28%
non-breast content; adding UWAS elimination lowers this to roughly 24%.
Downstream classification improves progressively X1 → X2 → X3 in Accuracy,
AUC and F1-score. The effect is small and consistent rather than large.

## Limitations

- Reference masks come from a per-image row threshold, not free-form
  delineation, and were produced by a single annotator without radiological
  review. No inter-annotator agreement is available.
- No classical baseline (e.g. horizontal intensity profile analysis) is
  implemented, so the benefit of a learned model over a rule-based
  transition-row detector is not quantified.
- X3 differs from X2 both in what is removed and in the resulting scale of
  the breast within the fixed input. The two effects are not separated. A
  control narrowing the crop by an equivalent but anatomically arbitrary
  amount would be needed.
- The 95% confidence intervals over the 100 classification runs describe
  run-to-run variability on a fixed image set, not sampling uncertainty. No
  hypothesis test is performed.
- Labels are BI-RADS categories, not histopathologically confirmed
  outcomes.
- Evaluation is in-distribution only; no external or multi-vendor
  validation.
