Explanation of Files

The mask_error.zip file contains the masks for the dataset — a total of 1,000 images.

The test_1.zip file contains the image_t1 and mask_error_t1 files, which include the first batch of images and their corresponding masks, referred to as Test1 in the article.

The test_2.zip file contains the image_t2 and mask_error_t2 files, which include the second batch of images and their corresponding masks, referred to as Test2 in the article.
